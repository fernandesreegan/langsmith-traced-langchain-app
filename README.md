# 🔍 LangChain + LangSmith Tracing

A simple Python application demonstrating **LLM tracing and observability** using LangChain, OpenAI, and LangSmith.

## 🚀 Features

- 🤖 Uses LangChain `ChatOpenAI`
- ⌨️ Accepts 3 prompts at runtime
- 🔍 Traces each LLM call in LangSmith
- ⏱️ Monitors response latency
- 🔢 Tracks token usage
- 🐞 Helps analyze unexpected/failed responses

## 🛠️ Tools

`Python` | `LangChain` | `OpenAI` | `LangSmith`

## ▶️ Run

```bash
pip install langchain langchain-openai python-dotenv
python traced_app.py
